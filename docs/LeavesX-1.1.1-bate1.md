# LeavesX 1.1.1-bate1

LeavesX 1.1.1 的首轮稳定性测试版本，当前仅提供 Minecraft 26.1.2 构建。

## 本版本内容

- 补齐 26.1.2 运行时代码改动，并整理为可以从源码重新应用的构建补丁。
- 新增 `/leavesx health`，用于查看 TPS、MSPT、区块、实体、内存、GC 和并行计算窗口等运行指标。
- 新增 `/leavesx report`，导出脱敏诊断报告；报告不写入玩家姓名、IP、坐标、聊天、配置内容或插件清单。
- 修正 LeavesX 配置重载后的重启提示，检测到需要重启的配置变化时会在后续启动前持续提示。
- 修复 Windows 构建环境下固定许可证资源的换行处理，避免不同平台产生校验差异。
- 修正 POI 行为回归测试对 Java lambda 编号的依赖，改为按回调签名识别测试目标。
- CI 增加完整测试、可分发 JAR 和 SHA256 校验文件的构建产物。
- 增加三轮启动、重启、诊断命令、配置重载、实体保存和正常退出的发布冒烟测试。

## 可用构建

- Minecraft 26.1.2

请根据服务器版本下载对应的 JAR 文件，不同版本不能混用。

这是测试版本。首次更换服务端前，请备份世界文件、插件和配置文件。
