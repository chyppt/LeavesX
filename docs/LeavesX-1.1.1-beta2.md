# LeavesX 1.1.1-beta2

本版本继续只提供 Minecraft 26.1.2 构建。

## 本版本内容

- 增加异步模块任务耗时诊断，区分完成、回退、失败、排队和队列峰值。
- 健康检查和脱敏报告显示最近约 60 秒的任务执行、排队耗时；采用有界秒桶，不保留逐任务历史。
- 单独记录寻路结果、有序存档屏障、提交容量和并行范围计算的等待，并区分服务器主线程与其他调用线程。统计为墙钟时间，不等于 CPU 时间或 MSPT；有序屏障包含提交等待，不能直接相加。
- 新增 `/leavesx config check`，只读检查 LeavesX 配置格式、配置值和需要重启的项目，不写回配置文件、不触发配置迁移、不重建线程池。
- 配置检查提示未知配置项、异步刷怪前置条件和功能依赖：包括水路快照未开启异步寻路、异步压缩未开启玩家存档等；旧配置别名仍可识别。
- 异步区块发送改为在主线程复制区块节数据，再由工作线程编码副本。光照、方块实体、区块监听和插件事件保持原有线程及顺序，反矿透使用原路径。此功能默认关闭。
- 区块数据完成编码前，后续方块更新和卸载包不能越过它；队列满时完整同步编码，后台编码失败时重新编码完整副本，不使用半成品。
- 编码结果发布后释放区块节副本和任务引用，避免待发送数据继续持有无用快照。
- 性能报告增加 MSPT 的 P99，与 P95、最长 Tick 和超时 Tick 数量一同展示；排除尚未采集的启动占位值。
- 过期寻路请求不再等待后台结果，直接丢弃消费端引用；后台任务仍负责清理快照，避免提前释放容量。
- 水中导航停止或被新请求替换时，尚未开始的旧搜索可直接跳过，减少排队后的无效计算；已开始的任务仍正常结束。
- 实体追踪在 16 人及以上时复用玩家身份索引，减少候选实体反复扫描玩家列表；少量玩家保留短线性扫描，追踪提交顺序不变。
- 修复玩家存档文件替换失败却被记为保存成功的问题；失败保留旧档并清理临时文件，恢复路径后后续保存可正常继续。
- 修复线程池持续拒绝任务时归属队列的递归回退，改为迭代排空，保持同一实体或玩家任务的 FIFO 顺序，避免大量任务造成调用栈增长。
- 发布冒烟测试改为直接检查 JAR 内嵌服务端 Manifest 中的 LeavesX 版本，并验证健康检查、报告导出、配置重载、实体保存和正常停服。
- 增加并发计数、只读配置检查和大队列关闭场景回归测试。
- 增加队列公平性、计时窗口过期、存档替换失败恢复回归测试。

- Minecraft 26.1.2
