# LeavesX 1.2.1 — Minecraft 26.2

本分支保存 Minecraft 26.2 的当前源码与构建补丁，不包含 26.1.2 分支本轮的全部新增优化。

## 本次源码更新

- 将 LeavesX 版本标识设为 `1.2.1`，构建通道为 `STABLE`。
- 保留当前 26.2 运行时和对应版本的 API 适配。
- 移除重复的玩家名占位符补丁，避免同一修改在源码构建时被重复应用。
- 同步现有容器透传补丁，维护源码与已构建运行时的一致性。
- 更新构建说明，排除本地缓存、构建日志、补丁拒绝文件及其他版本工作目录。

## 与 26.1.2 的差异

26.2 尚未同步本轮全部功能。已确认的差异包括：

- 实体 AI 工具仍使用木棍，尚未调整为木铲。
- 配方候选索引仍采用原有实现，尚未同步本轮缓存重构。
- 尚未同步本轮 UTF-8 网络缓冲优化。

不能仅因两个构建均标记为 1.2.1，就认定其新增功能完全相同。本次上传源码不改动已生成的 JAR，也不代替后续功能适配。

## 构建

使用 JDK 25，在本分支执行：

```bash
./gradlew applyAllPatches
./gradlew test createLeavesclipJar
```
