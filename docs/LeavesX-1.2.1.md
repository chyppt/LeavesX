# LeavesX 1.2.1

LeavesX 1.2.1 分别提供 Minecraft 26.1.2 和 26.2 的源码与本地构建。本页的新增优化说明对应 26.1.2 分支；两个分支当前并非功能完全同步，差异见下文。

## 版本差异

- 26.1.2 包含本页列出的本轮新增优化与 AI 木铲调整。
- 26.2 本次提交保存已构建的 26.2 运行时，并修正源码补丁链中的重复补丁；不以改版本号代替功能适配。
- 已确认 26.2 仍使用 AI 木棍，尚未同步本轮配方候选缓存重构及 UTF-8 网络缓冲优化。因此，不能把下列全部新增内容视为两个版本均已完成。

## 本版本内容

### 并行计算与调度

- 完善异步计算准入判断，任务量不足、分区不足、队列拥堵、线程池不可用或计算异常时使用一次完整的主线程回退。
- 回退路径不会混用未完成的工作线程结果，避免半成品状态进入实体、区块或网络提交阶段。
- 补充任务耗时、队列、拒绝、回退和拥有者线程等待诊断，便于定位“CPU 负载不高但 TPS 下降”的实际原因。
- 改进实体追踪提交前的准入检查，追踪快照计算和主线程提交边界保持清晰。
- 保留 Paper/Leaves 的线程安全边界；Bukkit 事件、世界状态写入和插件回调仍在拥有者线程执行。

### 区块与实体

- 复用稳定的区块卸载顺序数据，减少重复排序和临时对象。
- 优化区块发送快照、延迟区段处理和网络缓冲，减少多人进服、传送和高速移动时的编码分配。
- 改进实体追踪的快照筛选和目标距离排序，避免无效目标参与后续计算。
- 保留实体碰撞、TNT、红石、活塞、漏斗、箱子和区块票据的原有提交顺序。
- 保留命名实体、持久化实体和强制加载区块的生命周期语义。

### 生物与村民兼容性

- 保留村民恐慌、僵尸/掠夺者威胁识别、刷铁条件、交易和补货逻辑。
- 非活跃交易村民只跳过不必要的移动计算，交易和补货相关逻辑仍按原有条件执行。
- 26.1.2 的生物 AI 工具调整为木铲子，并保留村民交易补货所需的行为路径。
- 不通过实体数量限制、强制清除或改变生成条件来换取性能。

### 配方、网络与内存

- 配方候选索引使用不可变缓存，直接增删配方时正确失效；最终匹配仍调用原配方逻辑，不以缓存命中替代原版校验。
- 优化 UTF-8 字符串写入，减少可直接编码字符串的临时缓冲区。
- 复用 Java Deflater 输入缓冲，并在异常和关闭路径释放压缩器资源。
- 网络缓冲优化可通过 `leavesx.yml` 中的配置开关控制，关闭后回到原有编码路径。

### 随机数、世界生成与潜影贝

- 复用随机刻位置、群系角点和潜影贝附着方向数据，减少重复分配。
- 保留安全种子和世界生成确定性，不改变区块种子、结构生成或红石相关随机行为。

## 配置与兼容性

- Leaves 原生配置继续保存在 `leaves.yml`，LeavesX 独立配置保存在 `leavesx.yml`。
- 支持通过 `leavesx reload` 重载可热更新配置；需要重启的项目会在诊断中明确提示。
- 未引入 Fabric，也未改变 Bukkit/Paper API 的线程约束。
- 26.1.2 和 26.2 使用各自独立构建，JAR 不可跨 Minecraft 版本混用。

## 验证结果

- 26.1.2：322 个测试 XML，共 10,642 项测试；失败 0，错误 0，跳过 22。
- 26.2：532 个测试 XML，共 10,759 项测试；失败 0，错误 0，跳过 22。
- 两个版本使用独立测试实例，各执行 3 轮启动、保存和重启测试；每轮覆盖版本查询、健康检查、完整诊断、并行诊断、网络诊断、配置检查、配置重载、命名实体跨重启、`save-all flush` 和正常关服。
- 6/6 轮冒烟测试通过，未发现实体 Tick 异常、导致服务端退出的未处理异常、配置重载错误或关服超时；测试环境提示另列于下文。
- 每轮启动后校验 Leavesclip 生成的服务端 JAR，确认其 SHA-256 与发布包内的版本元数据一致，并检查实际服务端 Manifest 中的 `LeavesX-Version: 1.2.1`。后续启动可以复用已生成的 JAR，不代表每轮都重新打补丁。

### 验证范围与已知提示

- 上述结果是本地自动化测试和启动冒烟测试结果，不等同于生产服务器长时间压力测试，也不能证明所有 Bukkit/Paper 插件均兼容。
- 命名实体持久化测试使用带有 `PersistenceRequired`、`NoAI` 和无敌标记的僵尸，只验证该测试实体跨重启保留；未覆盖所有生物在战斗、传送和插件干预下的生命周期。
- 本次启动测试未实际搭建刷铁机、TNT 复制机、刷沙机或地狱门加载器。相关代码回归检查不能代替这些结构在真实存档中的运行验证。
- 超平坦测试实例首次生成时出现 `No key layers in MapLike[{}]`，与测试实例的生成参数有关；各轮启动、保存和关服均完成。
- 26.2 测试实例出现 Windows OSHI 性能计数器读取异常，以及系统报告读取进程信息时的空指针警告。日志显示这些异常被系统报告路径捕获，未阻止启动、保存或关服；当前不能将测试结果表述为“日志完全无异常”。
- 尚未进行同存档、同插件、同配置的性能对比，因此不宣称固定 TPS/MSPT 提升比例。

## 使用建议

首次替换服务端前请备份世界、插件、`leaves.yml`、`leavesx.yml` 及 Paper 配置。请使用与 Minecraft 版本完全对应的 JAR；不要把 26.1.2 构建用于 26.2，反之亦然。
